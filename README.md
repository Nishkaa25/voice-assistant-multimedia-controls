# Voice Assistant for MultiMedia Controls

## 5 B - Team 15 - Software Engineering

A hardware-based voice assistant designed to provide hands-free
control of multimedia playback through voice commands.

## Team Members

- C K Gagan Gowda
- Anudeepak Anpuraja
- Nishkaa V
- Ishanika Vinuthan

## Features

- Voice-based multimedia control
- Play, pause and resume
- Volume up and volume down
- Mute/unmute
- Next and previous track navigation
- Voice command feedback
- Unrecognized command handling
- Local audio/video processing
- Raspberry Pi/ESP32 hardware integration
- MediaPipe-based gesture support

## Technology Stack

- Python
- Speech Recognition
- MediaPipe
- Raspberry Pi / ESP32
- PyAudio
- MQTT / WebSockets / UART
- OS media control APIs
